Ford Car Price Prediction

python · pandas · scikit-learn · random forest regressor · fastapi
Problem
Predict Ford car prices from vehicle specifications such as model, year, transmission, mileage, fuel type, tax, MPG, and engine size.
Method
Compared Linear Regression with Random Forest Regressor, then used a preprocessing pipeline and RandomizedSearchCV to tune the Random Forest model and select a stronger configuration.
Result
Final evaluation: MAE $1,076.82 · RMSE $1,566.14 · MSE $2,452,788.96. Built a FastAPI prediction endpoint and connected it to a frontend interface.

College Career Outcomes — Debt Status Classification

python · pandas · scikit-learn · random forest classifier · imbalanced classification
Problem
Classify debt status from a 227,980-row, 72-column dataset while avoiding reliance on debt-related fields that could leak the target.
Method
Cleaned and preprocessed the data, used stratified train/test splitting and balanced class weights, compared models, investigated feature leakage, and evaluated performance beyond overall accuracy.
Result
Random Forest achieved 87.5% test accuracy and 84.2% balanced accuracy. The project reinforced the importance of leakage detection and class-aware evaluation.
